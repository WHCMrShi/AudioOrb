# 声枢 AudioOrb v1.0.0

首个可用版本：一个 Windows 7 小工具式、只位于桌面的 Windows 11 输出设备切换器。

## 亮点

- 位于桌面层，普通应用会覆盖；Win+D 显示桌面时出现，不覆盖游戏。
- 单击在耳机与音响之间循环切换，支持两台以上设备。
- Fluent 2 Solid 实色卡片：中性表面、8 px 圆角、轻微 elevation；为避免 DWM 分层窗口圆角锯齿，不绘制外描边。
- 卡片常驻显示当前设备类型与适配器名称。
- 一个滑杆控制图标 / 名称 / 标准 / 宽四种布局；标准与宽显示当前系统音量。
- 设备图标按 form factor 与 PnP 容器稳定映射到 Segoe Fluent Icons；设置窗口使用 Mica，控件右对齐，左侧图标无底板。
- 新的 Fluent 分层蓝色渐变耳机图标；滚轮默认调整音量；设备页只保留启用开关；布局滑杆拖动时显示档位 tooltip。
- 滚轮可选择切换设备或调整系统音量；右键菜单可直接选择任意输出设备。
- 外观设置即时生效，不再显示冗余的实时预览；操作说明位于「常规」页。
- 拖动吸附、位置持久化、滚轮循环、全屏自动隐藏、开机启动、单实例。
- 主题（系统/浅色/深色）、宽度可调。
- 系统托盘图标与原生菜单（切换设备、设置、隐藏组件、开机启动、退出）。
- Fluent 风格蓝色圆角方块应用图标。
- 设置页 Mica + 可读性 scrim；原生菜单使用系统材质。
- 自包含 x64 包，无需安装 .NET 或 Windows App Runtime。

## 安装

下载 `AudioOrb-win-x64.zip`，解压后运行 `AudioOrb.exe`。首次运行会打开设置，选择要参与切换的两台设备即可。

配置与日志位置：

```text
%LOCALAPPDATA%\AudioOrb\settings.json
%LOCALAPPDATA%\AudioOrb\logs\app.log
```

## 系统要求

- Windows 11 x64（推荐）
- Windows 10 1809+ 理论上可运行，但未作为主要目标验证

## 修复

- 修复在设置中切换系统/浅色/深色主题时可能卡死或闪退的问题。

## 已知限制

- 已尝试非分层 + Mica / Acrylic / 直接 DWM backdrop，WinUI 3 对该无标题栏工具窗口仍退化为实色；按 Fluent 2 Material 降级为 Solid 实色材质。
- 依赖 Windows 未公开的 `IPolicyConfig` 接口。
- 仅提供 x64 构建。
- 部分独占全屏/反作弊游戏可能无法显示覆盖层；可在设置中关闭全屏自动隐藏。
